개인정보 처리방침

안놀랄개는 계정과 자체 서버를 두지 않는 온디바이스 중심 앱입니다. 아래 내용은 앱이 실제로 다루는 정보와 권한을 기준으로 작성했습니다.

시행일 2026.08.16버전 1.0
계정 없음회원가입·로그인 없이 사용합니다.
자체 서버 전송 없음프로필·훈련 기록·녹음은 기본적으로 기기에 저장됩니다.
광고·추적 없음광고 SDK나 사용자 추적 기능을 사용하지 않습니다.
직접 삭제 가능설정에서 훈련 기록 또는 전체 데이터를 삭제할 수 있습니다.

1. 적용 범위

본 개인정보 처리방침은 iOS용 반려견 생활소음 적응 훈련 앱 ‘안놀랄개’(이하 ‘앱’)에 적용됩니다. 앱 운영자는 서비스 제공에 필요한 최소한의 정보만 다루며, 앱 내부 기능을 위해 생성되는 데이터는 원칙적으로 사용자의 기기 안에서 처리합니다.

2. 앱에서 다루는 정보

구분예시처리 목적저장 위치
강아지 프로필이름, 생년월일(선택), 선택한 프로필 사진강아지별 훈련 화면과 기록 구분사용자 기기
훈련 설정선택한 생활소리, 현재 훈련 상태, 보정 볼륨자동 난이도 조절 및 다음 훈련 계획사용자 기기
훈련 기록훈련 일시, 반응 선택, 세션 결과, 노출 이력진행 상황 계산 및 기록 제공사용자 기기
사용자 녹음생활소음 녹음 파일, 길이, 음량 검사 결과실제 환경에 가까운 훈련 음원 제공사용자 기기
앱 설정훈련 알림 시간, 구매 기능 상태 확인에 필요한 로컬 값사용자 설정 유지사용자 기기 및 Apple 시스템

앱은 사용자의 이름, 전화번호, 주소, 위치정보, 광고 식별자 또는 연락처 목록을 훈련 기능을 위해 요구하지 않습니다.

3. 기기 권한

마이크

사용자가 ‘실제 소리 녹음하기’를 선택한 경우에만 마이크 권한을 사용합니다. 녹음은 기기에서 생성·처리·저장되며 앱 운영자의 서버로 업로드하지 않습니다.

사진 선택

강아지 프로필 사진을 고를 때 iOS 시스템 사진 선택기를 사용합니다. 사용자가 직접 선택한 이미지만 앱에 전달되며, 앱은 전체 사진 보관함 접근 권한을 요구하지 않습니다.

카메라

사용자가 프로필 사진을 직접 촬영하기로 선택한 경우에만 카메라 권한을 사용합니다. 촬영한 이미지는 프로필 사진 처리를 위해 앱의 로컬 저장소에 저장되며 안놀랄개 서버로 전송되지 않습니다.

알림

사용자가 훈련 알림을 직접 켠 경우 iOS 알림 권한을 사용합니다. 알림은 기기에서 예약되며 언제든 iOS 설정 또는 앱 설정에서 끌 수 있습니다.

4. 외부 전송 및 제3자 서비스

안놀랄개는 자체 회원 서버, 광고 네트워크, 행동 분석 SDK 또는 사용자 추적 SDK를 운영하지 않습니다. 앱의 프리미엄 구매 및 구매 복원은 Apple StoreKit을 통해 처리됩니다. 결제 수단과 카드 정보는 Apple이 처리하며 앱 운영자는 이를 직접 저장하지 않습니다.

Apple이 구매 및 App Store 서비스 제공 과정에서 처리하는 정보에는 Apple의 개인정보 처리방침과 약관이 적용됩니다.

5. 처리 목적

  • 강아지별 프로필과 훈련 대상 소리 표시
  • 훈련 반응 이력에 따른 다음 세션 강도 자동 조절
  • 사용자가 직접 녹음한 생활소리 재생
  • 훈련 기록과 진행 상태 제공
  • 사용자가 요청한 로컬 훈련 알림 제공
  • 프리미엄 구매 여부 확인 및 복원
  • 오류 문의 또는 개인정보 관련 요청에 대한 응답

6. 보관 기간과 삭제

기기 안의 프로필, 녹음 및 훈련 기록은 사용자가 삭제할 때까지 보관됩니다. 사용자는 앱의 설정에서 ‘훈련 기록 초기화’ 또는 ‘전체 데이터 삭제’를 실행할 수 있습니다. 전체 데이터 삭제 시 앱이 관리하는 프로필, 사진, 녹음 및 훈련 기록을 기기에서 삭제합니다.

앱 삭제 시 iOS의 앱 컨테이너에 저장된 로컬 데이터도 일반적으로 함께 제거됩니다. 단, App Store 구매 이력과 같은 Apple 계정 기반 정보는 Apple 시스템의 보관 정책에 따릅니다.

7. 사용자의 선택과 권리

  • 마이크·카메라·알림 권한은 iOS 설정에서 언제든 변경할 수 있습니다. 사진 선택은 iOS 시스템 사진 선택기를 통해 사용자가 고른 항목에 한해 이루어집니다.
  • 앱 설정에서 훈련 기록 또는 전체 로컬 데이터를 직접 삭제할 수 있습니다.
  • 자체 서버에 사용자 계정을 만들지 않으므로 별도의 서버 계정 삭제 절차는 없습니다.
  • 개인정보 처리와 관련한 질문은 아래 문의처로 보낼 수 있습니다.

8. 아동 및 연령 정보

앱은 사용자의 생년월일이나 실제 연령을 회원정보로 수집하지 않습니다. 강아지의 생년월일은 반려견 프로필을 위한 선택 정보이며 사용자의 연령 정보가 아닙니다.

9. 안전한 처리

안놀랄개는 데이터 전송을 최소화하는 방식으로 개인정보 노출 가능성을 줄입니다. 로컬 데이터는 iOS 앱 샌드박스 안에서 관리하며, 앱 운영자는 사용자의 기기 잠금·백업·Apple ID 보안 설정을 대신 통제할 수 없습니다. 기기 자체의 보안 기능을 함께 사용하는 것을 권장합니다.

10. 처리방침 변경

앱 기능, 데이터 처리 방식 또는 관련 법령이 변경되면 본 방침을 수정할 수 있습니다. 중요한 변경이 있는 경우 시행일과 변경 내용을 이 페이지 또는 앱을 통해 알립니다.
